# Typefield section storyboard

Open a Figma Design file in the desktop app. Import `manifest.json` from **Plugins → Development → Import plugin from manifest**, then run **Typefield section storyboard** from the Development submenu. Keep `code.js` in the same folder as the manifest.

The generator adds a page with 16 editable frames across desktop and mobile. Select either flow in Present mode and click **Turn the page**. Click the fold control to step through its three positions. **Build the object** takes the sample word back to the sculpture, and **Lab.** moves into the directory. The site scrubs the fold continuously with the page scroll. [Live Typefield](https://ejaubashi.github.io/t018/)
