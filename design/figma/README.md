# Typefield section storyboard

Open a Figma Design file in the desktop app. Import `manifest.json` from **Plugins → Development → Import plugin from manifest**, then run **Typefield section storyboard** from the Development submenu. Keep `code.js` in the same folder as the manifest.

The generator adds a new page with editable desktop and mobile frames. Select either flow in Present mode. The Exhibit link passes through the fold into Studio, **Build the object** takes the sample word back to the sculpture, and **Lab.** moves into the directory. The scroll positions are represented by storyboard frames. The live site links the fold continuously to the viewport. [Live Typefield](https://ejaubashi.github.io/t018/)
