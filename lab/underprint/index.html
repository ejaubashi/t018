Underprint

Sweep a lens across a sentence to find the one underneath.

I LEFT THE ROOM EMPTY.

YOU LEFT THIS ROOM IN ME.

Implementation

Two passages share a grid. Registered CSS properties carry the lens position into a live, six-sided shape() clip. Older browsers use an ellipse. The reveal button lets keyboard and screen-reader users read either passage in full. CSS shape()
