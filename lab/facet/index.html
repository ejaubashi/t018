Implementation

Each of the 24 ridges has one face at −45° and one at +45°. Each face shows a slice of a full text layout. An orthographic projection aligns the slices at the endpoints. A registered CSS angle animates the rotation, and sibling-index() positions the ridges where supported. The angle control works in half-degree steps. Registered CSS properties · Sibling index
