Implementation

Native input events record committed edits and their timing. Intl.Segmenter keeps grapheme clusters together when a deletion leaves an afterimage. An ordered tape replays edits and pauses. Recordings longer than eight seconds are compressed for playback. CSS sibling-index() positions the recent traces, with index values as a fallback. InputEvent · Sibling index
