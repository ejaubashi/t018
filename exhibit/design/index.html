Letters can be the thing you pass through
Kinetic Typography Page Transition brings background letters forward until they uncover the next view. TextClipScroll uses letter-shaped cutouts to reveal moving layers. Typefield brings both ideas into the fold. At the halfway point, the gaps in the hinged panels reveal the new word through a stencil made from the old one. Kinetic Typography Page Transition · TextClipScroll
Width changes the character of a heading
Atelier Triay describes the compressed Bricolage cuts as tense, with the wider cuts taking cues from Antique Olive. Typefield ties that same width axis to the camera. The heading tightens while a diagonal exposure crosses the sculpture and the interface moves from amber to violet. Bricolage Grotesque
Motion can show the destination before a click
Letter Shuffle Menu turns the letters of a word into the initials of menu destinations. Typefield lets the Lab category set a line of real experiment titles. In Studio the same idea previews a different destination. Focus or edit a field to see its word printed behind the form before building the object. Letter Shuffle Menu

What the references show

Position can carry a story
Codrops’ layout studies move image sets between arrangements using Flip and ScrollTrigger. An item already in view gives the eye a reference when the layout changes. Typefield uses the actual headings and sculpture for that continuity. Scroll-Based Layout Animations
A transition can belong to a particular entrance
Interlude makes each phrase on its home page the entry to its own transition. Its November 2026 source also restores focus inside the destination. In Typefield, the typographic motion should explain where a link went and put the keyboard in the place it opened. Interlude
One object can have two arrangements
Bookbinder’s proof layouts show how the same pages sit together on a printed sheet before folding. Typefield can offer those two views of a single page directly. The sheet makes the whole publication legible at once, and the reading view gives each section room. Bookbinder

Five designs to test

Proof sheet

See the whole edition, then enter any part. A long scroll composes itself into three plates. On wide screens Exhibit spans two rows beside Studio and Lab. On phones it sits above both, in reading order. Lilac, ink, and plum make the sections recognisable when their scale changes.

CSS Grid changes the layout of the existing elements. Named snapshots carry visible headings and the sculpture across the reflow. The test is to pause halfway through a fold, open the sheet, close it, and recover the same words, viewing angle, and fold position. Document view transitions

Split spread

Pull two chapters into the same spread. A divider between Exhibit and Studio opens so the sculpture can sit beside the fields that form it. Pull it back and the edited word becomes the sculpture’s caption. Give either side enough width to work without closing the spread.

Use a keyboard-adjustable divider and size the typography with container queries. At phone widths stack both chapters and keep the edited word visible as the bridge. Test whether someone can adjust a word and inspect its result while keeping both controls within reach. Container queries

Shared margin

Let a word open the margin beside it. Choose “angle” in Exhibit and a sample from Facet takes its place on the same baseline in the margin. The margin then extends into Lab while the source word holds its position.

Anchor the sample to the word, offer an inline position on narrow screens, and match the label when navigating into the room. Test whether returning from the experiment restores the actual word and line. CSS anchor positioning

Parallel editions

Compose on one screen and read on another. Open a second Typefield window on the proof sheet. A word written in Studio changes the print on the other screen while the two windows hold their own reading positions. Each window uses typography suited to its role.

Relay already synchronizes words between windows. Publish the committed word pair with that pattern and keep scroll and focus local. Test whether both windows show the same print after either writer reconnects. Relay experiment · Broadcast Channel API

Reorder the edition

Change the order while the edition stays alive. Place Studio before Exhibit and the publication becomes an invitation to write before seeing the sculpture. Move Lab to the front and the catalogue becomes the opening. The navigation, focus order, and section transitions follow the new sequence.

Move the actual sections with moveBefore() where supported. A saved order can also be applied at page load. Test with an unfinished word and a paused score. Both should survive the change in sequence. State-preserving DOM moves

The proof sheet comes first because it lets a reader see and choose among all three sections in one place. Layout, state, and navigation remain connected when the page changes scale.
